# Familjekalendern 4.0

En enkel Android-app för familjens gemensamma planering.

## Första versionen
- Mörkt gränssnitt med lila accenter
- Månadskalender
- Dagsöversikt och färgkodade aktiviteter
- Lägg till aktiviteter
- Lägg till familjemedlemmar och valfri roll
- Automatisk APK-build via GitHub Actions

APK-filen skapas som en GitHub Actions-artifact med namnet `Familjekalender-4.0-debug`.
